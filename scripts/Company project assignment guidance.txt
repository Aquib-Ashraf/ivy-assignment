Step 2: The pull script (do this once, work off the dump forever)

Pseudocode — you'll run this yourself:

```
for endpoint in [listings, rentals, projects]:
    page = 1
    all_records = []
    while true:
        resp = GET /v1/{endpoint}?api_key=KEY&limit=200&page=page
        all_records += resp.results
        if len(all_records) >= resp.total or resp.results is empty: break
        page += 1
    save_json(f"{endpoint}.json", all_records)
log resp.total from page 1 vs len(all_records) at the end — mismatch = finding
```
